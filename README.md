# Data Professional Survey Analysis – Power BI Dashboard

## Problem Statement

The objective of this project is to analyze survey data collected from data professionals and build an interactive dashboard to understand salary trends, job roles, programming language preferences, and work-life balance.

## Dataset

The dataset contains survey responses from data professionals across multiple countries.
It includes the following fields:

* Job Title
* Salary
* Country
* Favorite Programming Language
* Work-Life Balance Rating
* Salary Satisfaction
* Difficulty to Break into Data Field

## Data Cleaning and Preparation

Data cleaning was performed using Power Query:

* Removed unnecessary columns
* Fixed data type errors
* Handled missing values
* Converted date and time columns using locale settings
* Created calculated columns for analysis

## Data Visualization

An interactive dashboard was created in Power BI with the following visuals:

* Average salary by job title
* Favorite programming language distribution
* Work-life balance score
* Salary satisfaction score
* Country-wise survey participation
* Difficulty to enter data field
