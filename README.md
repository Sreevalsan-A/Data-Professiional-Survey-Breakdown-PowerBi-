# Data Professional Survey Dashboard (Power BI)

## Project Overview

This project is a Power BI dashboard created using the Data Professional Survey dataset.
The dashboard analyzes responses from data professionals and provides insights into salary, job roles, programming languages, and work-life balance.

## Tools Used

Power BI
Power Query
Excel
Data Cleaning
Data Visualization

## Dashboard Insights

Average salary by job title
Favorite programming language
Work-life balance rating
Salary satisfaction score
Country of survey takers
Difficulty to break into the data field
